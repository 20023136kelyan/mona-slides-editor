# Mona Slides React app

This workspace is the incremental React replacement for the Vue/PPTist editor. It is a side-by-side foundation until each editor slice passes the parity matrix; it is not yet the production editor.

From the repository root:

```sh
npm run dev:react
npm run lint:react
npm run test:react
npm run e2e:react
npm run build:react
```

See [`doc/REACT_FOUNDATION.md`](../../doc/REACT_FOUNDATION.md) and [`doc/REACT_MIGRATION_BLUEPRINT.md`](../../doc/REACT_MIGRATION_BLUEPRINT.md) for the selected versions, architecture, and replacement gates.
