# @mona/pptx-parser

Mona's browser-side PowerPoint parser.

This package is a maintained fork of `pptxtojson` 2.1.0. It keeps native
OOXML object identity (`cNvPr`, placeholder metadata, source part, and source
layer) attached to every parsed element so the editor can address the original
PowerPoint object without name- or ordering-based reconciliation.

The upstream MIT license is retained in `LICENSE`.
