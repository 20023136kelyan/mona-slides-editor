# PPTX fidelity corpus

This directory is for presentation fixtures used to compare the Vue reference application with the React migration.

- `public/` contains redistribution-safe decks that may be committed.
- `private/` is gitignored. Put confidential or personally owned decks there for local fidelity testing.

Real decks do not need manifests. The probe records element/type survival, warnings, round-trip behavior, and before/after renders. Never move a private deck into the public directory without confirming redistribution permission.
